# ZyneLabs Family VPN 🛡️

One-button WARP VPN for the family — dead simple, no setup needed.

## What is it?
An ultra-simple Android VPN app built for non-tech family members. One big button, powered by Cloudflare WARP. No accounts, no configuration, no confusion.

## How to use
1. Install the APK below
2. Tap the big connect button
3. Allow the VPN permission when Android asks
4. Done — you're protected 🟢

## Download
Get the APK from the [Releases](../../releases) page.

## Details
- Package: `com.dzinlabs.familyvpn`
- Network: Cloudflare WARP (WireGuard)
- Built with: WarpWG base, Burmese UI
